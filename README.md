# Movie Ticket Booking Management Application

## Overview
A Pega Platform application for managing movie ticket booking requests from request submission through booking confirmation and ticket processing.

## Case Type
Movie Ticket Request

## Features
- Submit movie ticket requests
- Check show availability
- Calculate booking cost
- Confirm booking requests
- Maintain movie and show data
- Review booking details
- Process ticket bookings
- Send booking confirmation notifications
- Define booking SLA
- Route booking requests based on show type

## Technology
- Pega Platform
- App Studio
- Dev Studio
- Case Lifecycle
- Data Model
- Data Transforms
- Workflow Automation

## Main Data
- Customer
- Movie
- Show
- Theatre
- Ticket
- Booking Request
- Notification

## Workflow
Request Intake → Availability Review → Cost Calculation → Booking Processing → Confirmation Notification
